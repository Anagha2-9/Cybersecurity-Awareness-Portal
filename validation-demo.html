🔍 Validation Rules & Regular Expressions

The JavaScript code in js/validation.js enforces the following pattern rules:

1. Name Pattern: /^[A-Za-z\s]{3,}$/ Letters and spaces only, minimum 3 characters.
2. Email Pattern: /^[^\s@]+@[^\s@]+\.[^\s@]+$/ Ensures standard username@domain.extension format.
3. Mobile Pattern: /^[0-9]{10}$/ Exact 10 numerical digits.
