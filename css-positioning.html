CSS Positioning & Properties Showcase

Visual demonstrations of CSS positioning schemes (static, relative, absolute, fixed, sticky), stacking contexts with z-index, and properties like float, clear, overflow, and opacity.

📌 Live Sticky Header: position: sticky; top: 75px; Notice how this bar remains stuck beneath the navbar while scrolling down!

1. Static & Relative Positioning

static is the normal default flow. relative offsets the element without affecting sibling positions:

Static Element 1: Default document flow (top/left offsets have no effect).
Relative Element: Offset by top: 12px; left: 20px; relative to its original position!

2. Absolute Positioning

absolute removes element from document flow and positions it relative to its closest positioned ancestor:

Parent Container has position: relative;

🚨 Absolute Badge: top: 15px; right: 15px;

This red emergency badge stays anchored to the top-right corner of this card regardless of other sibling content.

3. Stacking Context (z-index)

Controls layer order along the 3D Z-axis. Higher z-index values render on top:

Layer 1
z-index: 1
Layer 2
z-index: 2
Layer 3 (Top)
z-index: 3

4. Float, Clear & Overflow

Demonstrating text wrapping around a floated security icon and clear handling:

🛡️ Floated Icon
float: left;

This paragraph text dynamically flows and wraps around the floated box to the left. Floated elements were traditionally used for newspaper-style layouts. The container uses overflow: auto to form a clearfix block preventing layout collapse.

↑ Cleared using clear: both;

5. Fixed Positioning (position: fixed)

Look at the bottom-right corner of your browser screen. You will see the purple floating pill: "📞 Cyber Hotline (Fixed)". It has position: fixed; bottom: 25px; right: 25px; and stays locked in place even when you scroll up or down!
