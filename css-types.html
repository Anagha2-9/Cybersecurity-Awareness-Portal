Practical 03

Inline, Internal and External CSS Demonstration

Demonstrates the three methods of attaching Cascading Style Sheets (CSS) to an HTML document and their cascading precedence.

1. External CSS

<link rel="stylesheet">

Rules are written in standalone .css files (e.g. css/style.css) and linked in the <head>.

<!-- In HTML head -->
<link rel="stylesheet" href="css/style.css">

✅ Best Practice: Separates presentation from content across an entire multi-page website.

2. Internal CSS

<style> in <head>

Rules are embedded inside a <style> block within the document's <head> section.

🔐 Internal CSS Styled Advisory Box

This box is styled by .internal-css-box defined directly in this page's <style> tag.

💡 Useful when a single page requires unique, custom styles not shared elsewhere.

3. Inline CSS

style="..." attribute

Rules applied directly to a single specific HTML tag using the style attribute.

⚠️ Inline Styled Security Alert

Styled with: style="background-color: #451a03; border: 2px solid #f59e0b;"

⚠️ Highest specificity, but harder to maintain if overused.

4. The Cascading Precedence Demonstration

What happens when the same element is styled by External, Internal, and Inline CSS? The browser resolves conflicts according to specificity: Inline CSS > Internal CSS > External CSS > Browser Default.
