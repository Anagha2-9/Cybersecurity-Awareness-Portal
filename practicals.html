🎓 Viva Voce & Examiner Interview Guide (1 to 15)

Essential viva answers aligned with each specific practical in your syllabus:

Prac 01: Headings, Lists & Images

Q: What is the semantic difference between <ol>, <ul>, and <dl>?
Ans: <ol> represents ordered numerical sequences (steps); <ul> represents bulleted items where order doesn't matter; <dl> represents name-value description pairs (glossaries).

Prac 02: Semantic HTML

Q: Why are semantic landmarks important?
Ans: They communicate content purpose to screen readers for accessibility and help search engine crawlers index main articles versus peripheral headers or footers.

Prac 03: Inline, Internal & External CSS

Q: What is the order of cascading specificity?
Ans: Inline CSS (style attribute) overrides Internal CSS (in <style> tag), which overrides External CSS (linked .css file), which overrides browser defaults.

Prac 04: Responsive Design (Flex & Grid)

Q: When should you pick Flexbox over CSS Grid?
Ans: Flexbox is 1-dimensional (arranges items along a row OR column, e.g. navbar). Grid is 2-dimensional (controls rows AND columns simultaneously, e.g. cards grid).

Prac 05: CSS Positioning & Properties

Q: Contrast absolute vs fixed vs sticky positioning.
Ans: absolute positions relative to closest positioned ancestor; fixed stays anchored to the viewport even during scroll; sticky toggles between relative and fixed depending on scroll threshold.

Prac 06: JS Linking, Events & Array Methods

Q: Differentiate between map(), filter(), and reduce().
Ans: map() transforms every element into a new array; filter() selects elements matching a boolean predicate; reduce() accumulates all elements into a single aggregate result.

Prac 07: Frontend Form Validation

Q: Why use event.preventDefault() during form submission?
Ans: It stops the browser from triggering its default HTTP page reload, enabling client JavaScript to validate input patterns before allowing submission.

Prac 08: React SPA & Functional Components

Q: What is JSX and how does an SPA work?
Ans: JSX is JavaScript XML syntax allowing HTML-like templates inside JS. An SPA dynamically updates the DOM without requesting entire HTML pages from the server.

Prac 09: React Hooks (useState & useEffect)

Q: What is useEffect used for in React?
Ans: It performs side-effects (data fetching, subscriptions, timer management, DOM updates) after render, and returns a cleanup function to prevent memory leaks.

Prac 10: Fetch API & JSON

Q: Why is response.json() asynchronous?
Ans: The HTTP response body arrives as a stream of raw bytes. response.json() reads the full stream and parses it into a JavaScript object asynchronously.

Prac 11: DOM Manipulation & Events

Q: What is event bubbling?
Ans: When an event triggers on an innermost child element, it propagates upward through parent ancestors in the DOM hierarchy unless stopped by event.stopPropagation().

Prac 12: PHP Sessions & String Functions

Q: Where are PHP sessions stored and how do they work?
Ans: Session data is stored on the server file system identified by a unique Session ID cookie (`PHPSESSID`) transmitted in client request headers.

Prac 13: PHP-MySQL Connectivity & CRUD

Q: How do PDO prepared statements stop SQL Injection?
Ans: The SQL command structure is sent and compiled first. Parameters are bound separately, ensuring attacker input is never interpreted as executable SQL statements.

Prac 14: Express Server & Static Resources

Q: What is the role of express.static()?
Ans: It is a built-in middleware function that serves static assets like HTML files, stylesheets, client JavaScript, and media directly from a directory without manual route handlers.

Prac 15: REST API & Database Connectivity

Q: Explain REST operations mapped to HTTP methods and MySQL queries.
Ans: POST maps to SQL INSERT (HTTP 201); GET maps to SQL SELECT (HTTP 200); PUT maps to SQL UPDATE (HTTP 200); DELETE maps to SQL DELETE (HTTP 200).
